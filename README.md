# YIHE DuaVerse Website

Static responsive website for Yihe DuaVerse.

## Files
- `index.html` — website structure and content
- `style.css` — responsive design
- `assets/yihe-logo.png` — supplied YIHE logo
- `assets/duaverse-logo.png` — supplied DuaVerse logo
- `assets/hero-home-clean.jpg` — flag-free logistics hero image

## Local preview
Open `index.html` in a browser.

## Deployment
The site is ready for GitHub + Cloudflare Pages deployment. No server-side code is required for the current enquiry form; it opens the visitor's email client.
